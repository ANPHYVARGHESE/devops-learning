ping

Tests connectivity between your system and another host.

Example:

ping google.com
curl

Retrieves data from a website or API.

Example:

curl https://google.com

View only HTTP headers:

curl -I https://google.com
hostname -I

Displays the IP address of the current system.

Example:

hostname -I
ss -tuln

Displays listening network ports and services.

Example:

ss -tuln

Common Ports:

Port	Service
22	SSH
80	HTTP
443	HTTPS
3306	MySQL
5432	PostgreSQL

What is a Process?

A process is a running instance of a program. Every application running on a Linux system has a unique Process ID (PID).

Examples:

nginx web server
Docker daemon
Python application
SSH service
Useful Commands
View Running Processes
ps -ef

Displays all running processes.

Real-Time Process Monitoring
top

Shows CPU and memory usage of running processes.

Stop a Process
kill PID

Example:

kill 1234
Force Stop a Process
kill -9 PID

Example:

kill -9 1234
